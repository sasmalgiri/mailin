# mailin 4.0 — App Store listing (Deutsch)

## Subtitle

Alte E-Mails öffnen & suchen

## Promotional text

Große E-Mail-Archive schnell öffnen, Ordner und Anhänge behalten, Wichtiges finden, Duplikate sicher behandeln, mit Nachweis exportieren. Mit Live Mail wächst es weiter.

## Description

Öffnen Sie große E-Mail-Archive schnell. Behalten Sie Ihre Ordner und Anhänge. Finden Sie, was zählt. Behandeln Sie Duplikate sicher. Exportieren Sie mit Prüfung. Und lassen Sie das Archiv weiterwachsen – mit optionaler Aufbewahrung Ihrer Live Mail, ganz auf Ihrem eigenen Mac, iPhone oder iPad.

1. GROSSE ARCHIVE SCHNELL ÖFFNEN
• MBOX (Google Takeout, Thunderbird, Apple Mail), EML, EMLX, MSG, PST, OST, Outlook für Mac (OLM), Lotus Notes (NSF) und ZIP – einfach die Datei hineinziehen.
• Schneller Import liest Postfachdateien parallel: In unseren Tests wurde ein 213 MB großes Postfach mit 56.699 Nachrichten auf einem Mac mit Apple Silicon in etwa 30 Sekunden importiert.
• Liest direkt von der Festplatte: Die Größe begrenzt nur Ihr Speicher, nicht mailin. Die App nennt genau, was sie nicht lesen konnte, und ein unterbrochener Import wird von selbst fortgesetzt.

2. ORDNER UND ANHÄNGE BEHALTEN
• Outlook-Ordner kommen so an, wie sie waren, auch leere; Gmail-Labels bleiben Labels – eine Nachricht, alle ihre Labels.
• Anhänge und Nachrichtendetails bleiben bei jeder Nachricht. Das Archiv bewahrt eine eigene geprüfte Kopie jeder Postfachdatei auf und funktioniert daher weiter, wenn das Original verschoben oder gelöscht wird.

3. FINDEN, WAS ZÄHLT
• Sucht in PDF-, Word-, Excel-, PowerPoint- und Pages-Dateien sowie in gescannten Bildern und Fotos (OCR auf dem Gerät) – und zeigt, wo der Treffer ist: Der Text des Anhangs öffnet sich bei den markierten Wörtern.
• Erweiterte Suche (AND / OR / NOT, Datum, Absender, Bedingungen für Anhänge) und die Option „Ganze Wörter“ – in jedem Tarif. Jede Suche sagt, wie viel des Archivs sie abgedeckt hat.

4. DUPLIKATE SICHER BEHANDELN
• Bytegleiche Kopien werden von bloß ähnlichen Nachrichten unterschieden, die nie in Massen entfernt werden. Sie sehen zuerst die Anzahl, und entfernte Kopien landen im Papierkorb, aus dem Sie sie wiederherstellen können.
• Wird dasselbe Postfach erneut hinzugefügt, kommt nichts doppelt hinzu.

5. MIT PRÜFUNG EXPORTIEREN
• PST, MBOX, EML, PDF (ein PDF pro Nachricht, benannt nach dem Betreff), CSV und mehr.
• Jeder Export endet mit einem Beleg: Die Ausgabe wird zurückgelesen und mit dem Archiv verglichen, jede Abweichung wird benannt – so wissen Sie, dass Ihre Mails sicher sind, bevor Sie sie vom Server löschen. Unterbrochene Exporte werden fortgesetzt.

WEITERWACHSEN LASSEN
• Fügen Sie jederzeit neue Postfachdateien hinzu; Nachrichten, die schon im Archiv sind, werden übersprungen.
• Optionale Aufbewahrung Ihrer Live Mail: Verbinden Sie Outlook / Microsoft 365, Gmail, iCloud Mail, Fastmail oder ein beliebiges IMAP-Konto, und jede neue Nachricht wird in Ihrem Archiv gespeichert – und bleibt dort, auch wenn der Server sie löscht. Aus, bis Sie ein Konto hinzufügen; Ihr Gerät spricht direkt mit Ihrem Anbieter, ohne mailin-Server oder Relay.
• Sie legen fest, was jedes Konto darf: „Mails aufbewahren“, „E-Mails senden“, „Mails auf dem Server ändern“ (nur Änderungen, die Sie bestätigen). Gmail verbindet sich mit einem Google-App-Passwort; Outlook meldet sich auf der eigenen Seite von Microsoft an. Passwörter und Tokens bleiben im Schlüsselbund dieses Geräts.

AUSSERDEM ENTHALTEN
• Ein Postfach zum Lesen, Schreiben und Senden: Formatierung, Signaturen, Dateien oder archivierte Nachrichten anhängen, Senden widerrufen.
• Dieselben Archivfunktionen auf iPhone und iPad sowie Rezepte, die Schritt für Schritt durch häufige Aufgaben führen.
• Tarif Professional: Verwahrer und Legal Holds, Beweismittelkette, Prüfung und Produktion mit Bates-Nummerierung, Wiederherstellung gelöschter Mails, die noch in Postfachdateien stecken.
• Optionale KI-Einblicke auf dem Gerät (Apple Intelligence), aus, bis Sie sie einschalten.

PRIVAT VON GRUND AUF
• Kein mailin-Server, keine Analysen, kein Tracking, kein Konto bei uns. Keine Cloud-KI.

Tarife: Kostenlos, Personal und Professional, monatlich, jährlich oder lebenslang – unverändert. Nutzungsbedingungen: https://sasmalgiri.github.io/mailin/terms/

## What's New

LIVE MAIL – DIE FÜNF AUFGABEN FUNKTIONIEREN JETZT AUCH MIT IHREN AKTUELLEN MAILS
• Verbinden Sie Outlook und Microsoft 365, Gmail, iCloud Mail, Fastmail oder ein beliebiges IMAP-Konto – optional, aus, bis Sie eines hinzufügen. Ihr Gerät spricht direkt mit Ihrem Anbieter: kein mailin-Server, kein Relay.
• „Mails aufbewahren“ speichert eine schreibgeschützte Kopie jeder Nachricht in Ihrem Archiv, sodass Ordner, Suche, Duplikate und geprüfter Export damit funktionieren – und sie bleibt erhalten, auch wenn der Server sie löscht.
• Ein Postfach im Stil von Apple Mail mit Werkzeugen im Stil von Thunderbird: Nachrichtenvorschau, Aktionen per Mauszeiger und Wischen, ein Schnellfilter (Text, ungelesen, markiert, Anhänge, Tags), farbige Tags, Konversationen, intelligente Ordner und Aktionen für mehrere Nachrichten auf einmal.
• Schreiben und senden: fett, kursiv, Farben, Listen und Links; Signaturen pro Konto; Dateien hineinziehen oder Nachrichten direkt aus Ihrem Archiv anhängen. „Senden widerrufen“ hält eine Nachricht zurück, bevor sie abgeht.
• Sie entscheiden, was jedes Konto darf: „Mails aufbewahren“, „E-Mails senden“ und „Mails auf dem Server ändern“ (markieren, kennzeichnen, in einen anderen Ordner bewegen, in den Papierkorb legen und wiederherstellen – nur, wenn Sie es verlangen, jede Änderung aufgelistet).
• Entfernen Sie ein Konto und behalten Sie seine Mails, oder löschen Sie sie mit – zuerst die Anzahl, dann der Fortschritt.
• Gmail verbindet sich mit einem Google-App-Passwort, Outlook mit der eigenen Anmeldung von Microsoft.

SCHNELLER IMPORT
• Große Postfächer werden um ein Vielfaches schneller importiert: Postfachdateien werden parallel gelesen, Duplikate werden aussortiert, nachdem alles gespeichert ist. Standardmäßig an; im Importfenster für jeden einzelnen Import abschaltbar.

AUSSERDEM NEU
• Die Erweiterte Suche gibt es jetzt in jedem Tarif – und nur einen Klick entfernt neben dem Suchfeld (⌥⇧⌘F), mit der Option „Ganze Wörter“ und einer Liste der Suchoperatoren.
• Neue Nachricht von jeder Seite aus (⌥⌘N).
• Lange E-Mails werden auf jeder Seite vollständig gedruckt; jedes Datum zeigt sein Jahr; Datumsbereich und Anzahlen beschreiben immer die ganze Liste.
• Rezepte zeigen, was sie gefunden und was sie geändert haben.
