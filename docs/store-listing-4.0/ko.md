# mailin 4.0 — App Store listing (Korean)

## Subtitle
오래된 이메일 열기, 검색, 보관

## Promotional text
대용량 이메일 아카이브를 빠르게 열고, 모든 폴더와 첨부 파일을 지키고, 필요한 것을 찾고, 중복을 안전하게 처리하고, 검증과 함께 내보내세요. 라이브 메일로 계속 늘려 가세요.

## Description
대용량 이메일 아카이브를 빠르게 엽니다. 폴더와 첨부 파일을 그대로 지킵니다. 필요한 것을 찾습니다. 중복을 안전하게 처리합니다. 검증과 함께 내보냅니다. 그리고 선택 사항인 라이브 메일 보존으로 아카이브를 계속 늘려 갈 수 있습니다. 이 모든 것이 사용자의 Mac, iPhone 또는 iPad 안에서 이루어집니다.

1. 대용량 아카이브를 빠르게 열기
• MBOX(Google Takeout, Thunderbird, Apple Mail), EML, EMLX, MSG, PST, OST, Outlook for Mac(OLM), Lotus Notes(NSF), ZIP을 지원합니다. 파일을 끌어다 놓기만 하면 됩니다.
• 빠른 가져오기는 메일함 파일을 병렬로 읽습니다. 자체 테스트에서 56,699개의 메시지가 담긴 213 MB 메일함을 Apple-silicon Mac에서 약 30초 만에 가져왔습니다.
• 디스크에서 순차적으로 읽기 때문에 크기를 제한하는 것은 mailin이 아니라 저장 공간입니다. 읽지 못한 항목은 정확히 알려 주며, 중단된 가져오기는 자동으로 다시 시작됩니다.

2. 폴더와 첨부 파일을 그대로 지키기
• Outlook 폴더는 빈 폴더까지 원래 모습 그대로 가져옵니다. Gmail 레이블은 레이블 그대로 유지됩니다. 메시지 하나에 해당 레이블이 모두 붙습니다.
• 첨부 파일과 메시지 세부 정보는 모든 메시지와 함께 보관됩니다. 아카이브는 각 메일함 파일의 검증된 사본을 자체적으로 보관하므로, 원본을 옮기거나 삭제해도 계속 사용할 수 있습니다.

3. 필요한 것 찾기
• PDF, Word, Excel, PowerPoint, Pages 파일 안의 내용은 물론, 스캔한 이미지와 사진(기기 내 OCR)까지 검색합니다. 일치하는 위치를 보여 주고, 강조 표시된 단어 위치에서 첨부 파일의 텍스트를 엽니다.
• 고급 검색(AND / OR / NOT, 날짜, 보낸 사람, 첨부 파일 조건)과 전체 단어 옵션을 모든 요금제에서 사용할 수 있습니다. 모든 검색은 아카이브의 어느 범위까지 검색했는지 알려 줍니다.

4. 중복을 안전하게 처리하기
• 바이트 단위로 동일한 사본과 비슷해 보이는 메시지를 구분하며, 비슷해 보이는 메시지는 절대 일괄 삭제하지 않습니다. 먼저 개수를 확인할 수 있고, 삭제한 사본은 휴지통으로 이동하므로 복원할 수 있습니다.
• 같은 메일함을 다시 추가해도 중복으로 추가되는 것은 없습니다.

5. 검증과 함께 내보내기
• PST, MBOX, EML, PDF(메시지당 PDF 하나, 제목으로 파일 이름 지정), CSV 등으로 내보낼 수 있습니다.
• 모든 내보내기는 확인서로 마무리됩니다. 결과물을 다시 읽어 아카이브와 비교하고, 차이가 있으면 구체적으로 알려 줍니다. 그래서 서버에서 메일을 삭제하기 전에 메일이 안전한지 확인할 수 있습니다. 중단된 내보내기는 다시 시작됩니다.

아카이브를 계속 늘려 가기
• 언제든지 새 메일함 파일을 추가하세요. 이미 아카이브에 있는 메시지는 건너뜁니다.
• 선택 사항인 라이브 메일 보존: Outlook / Microsoft 365, Gmail, iCloud Mail, Fastmail 또는 모든 IMAP 계정을 연결하면 새 메시지가 모두 아카이브에 저장되며, 서버에서 삭제되더라도 아카이브에 남습니다. 계정을 추가하기 전까지는 꺼져 있습니다. 기기가 메일 제공업체와 직접 통신하며, mailin 서버나 중계 서버를 거치지 않습니다.
• 각 계정에 허용할 작업을 선택할 수 있습니다: 메일 보존, 메일 보내기, 서버 메일 변경(확인한 변경 사항만). Gmail은 Google 앱 비밀번호로 연결하고, Outlook은 Microsoft 자체 페이지에서 로그인합니다. 비밀번호와 토큰은 이 기기의 키체인에 보관됩니다.

추가 기능
• 메일을 읽고, 쓰고, 보낼 수 있는 메일함: 서식, 서명, 파일 또는 보관된 메시지 첨부, 보내기 취소.
• iPhone과 iPad에서도 동일한 아카이브 기능을 사용할 수 있으며, 자주 하는 작업을 단계별로 안내하는 레시피도 제공합니다.
• Professional 요금제: 관리인(커스터디언)과 법적 보존 조치(리걸 홀드), 증거 관리 연속성(Chain of Custody), Bates 번호를 사용한 검토 및 제출, 메일함 파일 안에 남아 있는 삭제된 메일 복구.
• 선택 사항인 기기 내 AI 인사이트(Apple Intelligence). 켜기 전까지는 꺼져 있습니다.

개인정보 보호를 우선한 설계
• mailin 서버 없음, 분석 없음, 추적 없음, 별도의 계정 가입 없음. 클라우드 AI도 사용하지 않습니다.

요금제: 무료, Personal, Professional. 월간, 연간 또는 평생 이용권 중에서 선택할 수 있습니다(변경 사항 없음). 이용 약관: https://sasmalgiri.github.io/mailin/terms/

## What's New
라이브 메일 — 이제 다섯 가지 작업을 라이브 메일에서도 할 수 있습니다
• Outlook 및 Microsoft 365, Gmail, iCloud Mail, Fastmail 또는 모든 IMAP 계정을 연결할 수 있습니다. 선택 사항이며, 계정을 추가하기 전까지는 꺼져 있습니다. 기기가 메일 제공업체와 직접 통신하며, mailin 서버나 중계 서버를 거치지 않습니다.
• 메일 보존은 모든 메시지의 읽기 전용 사본을 아카이브에 저장하므로 폴더, 검색, 중복 처리, 검증된 내보내기를 그대로 사용할 수 있으며, 서버에서 삭제되더라도 아카이브에 남습니다.
• Apple Mail 스타일의 메일함과 Thunderbird 스타일의 도구: 메시지 미리보기, 포인터를 올리거나 쓸어 넘기는 동작, 빠른 필터(텍스트, 읽지 않음, 깃발 표시, 첨부 파일, 태그), 색상 태그, 대화 보기, 스마트 폴더, 여러 메시지에 한꺼번에 적용하는 동작.
• 작성 및 보내기: 굵게, 기울임꼴, 색상, 목록, 링크. 계정별 서명. 파일을 끌어다 놓거나 아카이브에서 메시지를 바로 첨부할 수 있습니다. 보내기 취소로 메시지가 전송되기 전에 잠시 보류할 수 있습니다.
• 각 계정에 허용할 작업을 직접 정합니다: 메일 보존, 메일 보내기, 서버 메일 변경(읽음 표시, 깃발 표시, 다른 폴더로 이동, 휴지통으로 이동 및 복원. 요청할 때만 실행되며 모든 변경 사항이 목록으로 표시됩니다).
• 계정을 제거할 때 메일은 남겨 두거나 함께 삭제할 수 있습니다. 먼저 개수를 보여 주고, 이어서 진행 상황을 보여 줍니다.
• Gmail은 Google 앱 비밀번호로, Outlook은 Microsoft 자체 로그인으로 연결합니다.

빠른 가져오기
• 대용량 메일함을 몇 배 더 빠르게 가져옵니다. 메일함 파일을 병렬로 읽고, 모든 항목을 저장한 후에 중복을 정리합니다. 기본적으로 켜져 있으며, 가져오기 윈도우에서 개별 가져오기마다 끌 수 있습니다.

기타 새로운 기능
• 이제 고급 검색을 모든 요금제에서 사용할 수 있으며, 검색창 옆에서 클릭 한 번으로 열 수 있습니다(⌥⇧⌘F). 전체 단어 옵션과 검색 연산자 목록도 제공합니다.
• 어느 페이지에서든 새로운 메시지를 작성할 수 있습니다(⌥⌘N).
• 긴 이메일도 모든 페이지에 전체 내용이 인쇄됩니다. 모든 날짜에 연도가 표시되며, 날짜 범위와 개수는 항상 목록 전체를 기준으로 합니다.
• 레시피가 찾은 항목과 변경한 내용을 보여 줍니다.
