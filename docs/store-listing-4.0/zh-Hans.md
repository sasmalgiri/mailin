打开、搜索并保存旧邮件

## Promotional text

快速打开大型邮件归档，保留每个文件夹和附件，找到重要内容，安全处理重复项，导出并附带验证。还能通过实时邮件让归档持续增长。

## Description

快速打开大型邮件归档。保留文件夹和附件。找到重要内容。安全处理重复项。导出并附带验证。之后还可通过可选的实时邮件保全，让归档持续增长——一切都在你自己的 Mac、iPhone 或 iPad 上完成。

1. 快速打开大型归档
• 支持 MBOX（Google Takeout、Thunderbird、Apple Mail）、EML、EMLX、MSG、PST、OST、Outlook for Mac（OLM）、Lotus Notes（NSF）和 ZIP——直接拖入文件即可。
• 快速导入可并行读取邮箱文件：在我们的测试中，一个 213 MB、包含 56,699 封邮件的邮箱在 Apple-silicon Mac 上约 30 秒完成导入。
• 直接从磁盘流式读取，大小只受你的存储空间限制，而非 mailin。无法读取的内容会如实列出，导入中断后会自动继续。

2. 保留文件夹和附件
• Outlook 文件夹原样保留，空文件夹也不例外；Gmail 标签仍是标签——一封邮件，保留它的全部标签。
• 每封邮件都保留附件和邮件详情。归档会为每个邮箱文件保存一份经过验证的副本，即使原文件被移动或删除，归档依然可用。

3. 找到重要内容
• 可搜索 PDF、Word、Excel、PowerPoint 和 Pages 文件内部，以及扫描图像和照片（设备端 OCR）——并显示匹配位置，打开附件文本时直接定位到高亮的词语。
• 所有方案均提供高级搜索（AND / OR / NOT、日期、发件人、附件条件）和“全字匹配”选项。每次搜索都会说明覆盖了归档的多少内容。

4. 安全处理重复项
• 能区分逐字节完全相同的副本与仅仅相似的邮件，相似邮件绝不会被批量删除。你会先看到数量，删除的副本会移到废纸篓，可随时恢复。
• 再次添加同一个邮箱，不会重复添加任何内容。

5. 导出并附带验证
• 支持 PST、MBOX、EML、PDF（每封邮件一个 PDF，以主题命名）、CSV 等格式。
• 每次导出都会生成一份回执：读回导出结果并与归档比对，任何差异都会明确指出——让你在从服务器删除邮件之前，确认邮件已安全保存。导出中断后会自动继续。

让归档持续增长
• 随时添加新的邮箱文件；已在归档中的邮件会自动跳过。
• 可选的实时邮件保全：连接 Outlook / Microsoft 365、Gmail、iCloud Mail、Fastmail 或任何 IMAP 账户，每封新邮件都会保存到你的归档中——即使服务器删除了它，也依然保留。在你添加账户之前此功能保持关闭；你的设备直接与邮件服务商通信，不经过任何 mailin 服务器或中转。
• 由你决定每个账户可以做什么：保全邮件、发送邮件、更改服务器邮件（仅执行你确认的更改）。Gmail 通过 Google 应用专用密码连接；Outlook 在 Microsoft 自己的页面上登录。密码和令牌保存在本设备的钥匙串中。

同样包含
• 可阅读、撰写和发送邮件的邮箱：格式设置、签名、附加文件或已归档的邮件、撤销发送。
• iPhone 和 iPad 上提供同样的归档功能，还有逐步引导常见任务的配方。
• Professional 方案：保管人与法律保留、监管链、审阅与出示（含 Bates 编号）、恢复邮箱文件中仍存在的已删除邮件。
• 可选的设备端 AI 洞察（Apple Intelligence），在你开启之前保持关闭。

隐私至上的设计
• 没有 mailin 服务器，没有分析，没有跟踪，无需在我们这里注册账户。没有云端 AI。

方案：免费、Personal 和 Professional，按月、按年或终身——保持不变。使用条款：https://sasmalgiri.github.io/mailin/terms/

## What's New

实时邮件——五项任务现在也适用于你的实时邮件
• 连接 Outlook 和 Microsoft 365、Gmail、iCloud Mail、Fastmail 或任何 IMAP 账户——可选功能，在你添加账户之前保持关闭。你的设备直接与邮件服务商通信：没有 mailin 服务器，没有中转。
• “保全邮件”会将每封邮件的只读副本保存到你的归档中，让文件夹、搜索、重复项和验证导出都能作用于这些邮件——即使服务器删除了邮件，它也依然保留。
• Apple Mail 风格的邮箱，搭配 Thunderbird 风格的工具：邮件预览、悬停和轻扫操作、快速过滤（文本、未读、已标记、附件、标签）、彩色标签、对话、智能文件夹，以及同时对多封邮件执行操作。
• 撰写和发送：粗体、斜体、颜色、列表和链接；每个账户单独的签名；拖入文件，或直接从归档中附加邮件。“撤销发送”会在邮件发出前暂时保留。
• 由你决定每个账户可以做什么：保全邮件、发送邮件和更改服务器邮件（标记、加旗标、移到其他文件夹、移到废纸篓并恢复——仅在你要求时执行，每项更改都会列出）。
• 移除账户时可保留其邮件，也可一并删除——先显示数量，再显示进度。
• Gmail 通过 Google 应用专用密码连接；Outlook 使用 Microsoft 自己的登录页面。

快速导入
• 大型邮箱的导入速度提升数倍：并行读取邮箱文件，所有内容保存完毕后再整理重复项。默认开启；可在导入窗口中为任何一次导入单独关闭。

其他新功能
• 高级搜索现已在所有方案中提供——并且就在搜索框旁边，一键即达（⌥⇧⌘F），附带“全字匹配”选项和搜索运算符列表。
• 在任何页面新建邮件（⌥⌘N）。
• 长邮件在每一页上都完整打印；每个日期都显示年份；日期范围和数量始终描述整个列表。
• 配方会显示它找到了什么、更改了什么。
