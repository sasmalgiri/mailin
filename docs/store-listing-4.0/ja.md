# mailin 4.0 — App Store listing (Japanese)

## Subtitle
古いメールを開いて、検索して、残す

## Promotional text
大容量のメールアーカイブをすばやく開き、フォルダと添付ファイルをすべて残し、必要なものを見つけ、重複を安全に処理し、検証付きで書き出せます。ライブメールでアーカイブを育て続けることもできます。

## Description
大容量のメールアーカイブをすばやく開けます。フォルダと添付ファイルはそのまま残ります。必要なものを見つけられます。重複を安全に処理できます。検証付きで書き出せます。さらに、オプションのライブメール保全でアーカイブを育て続けることも。すべてお使いのMac、iPhone、iPadの中で完結します。

1. 大容量のアーカイブをすばやく開く
• MBOX(Google Takeout、Thunderbird、Apple Mail)、EML、EMLX、MSG、PST、OST、Outlook for Mac(OLM)、Lotus Notes(NSF)、ZIPに対応。ファイルをドロップするだけです。
• 高速読み込みはメールボックスファイルを並列で読み込みます。当社のテストでは、56,699通のメッセージを含む213 MBのメールボックスを、Apple-silicon Macで約30秒で読み込みました。
• ディスクから順次読み込むため、扱えるサイズを決めるのはmailinではなくストレージの容量です。読み込めなかったものは正確に表示され、中断した読み込みは自動的に再開します。

2. フォルダと添付ファイルをそのまま残す
• Outlookのフォルダは空のフォルダも含めて元の構成のまま取り込まれます。Gmailのラベルはラベルのまま。1通のメッセージに、そのすべてのラベルが付きます。
• 添付ファイルとメッセージの詳細は、すべてのメッセージとともに保存されます。アーカイブは各メールボックスファイルの検証済みコピーを独自に保持するため、元のファイルを移動または削除しても引き続き使えます。

3. 必要なものを見つける
• PDF、Word、Excel、PowerPoint、Pagesファイルの中身や、スキャン画像や写真(デバイス上のOCR)まで検索できます。一致した箇所も表示され、添付ファイルのテキストをハイライトされた語句の位置で開きます。
• 高度な検索(AND / OR / NOT、日付、送信者、添付ファイルの条件)と「単語単位」オプションを、すべてのプランで利用できます。どの検索でも、アーカイブのどれだけを対象にしたかが表示されます。

4. 重複を安全に処理する
• バイト単位で同一のコピーと、よく似たメッセージを区別します。よく似たメッセージが一括で削除されることはありません。最初に件数が表示され、削除したコピーはゴミ箱に移動するので、元に戻すことができます。
• 同じメールボックスをもう一度追加しても、重複して追加されることはありません。

5. 検証付きで書き出す
• PST、MBOX、EML、PDF(メッセージごとに1つのPDF、件名をファイル名に使用)、CSVなどに書き出せます。
• すべての書き出しの最後には受領証が作成されます。出力を読み戻してアーカイブと照合し、違いがあれば具体的に示します。サーバからメールを削除する前に、メールが安全であることを確かめられます。中断した書き出しは再開します。

アーカイブを育て続ける
• 新しいメールボックスファイルはいつでも追加できます。すでにアーカイブにあるメッセージはスキップされます。
• オプションのライブメール保全:Outlook / Microsoft 365、Gmail、iCloud Mail、Fastmail、または任意のIMAPアカウントを接続すると、新しいメッセージがすべてアーカイブに保存されます。サーバ側で削除されても、アーカイブには残ります。アカウントを追加するまではオフです。デバイスはプロバイダと直接通信し、mailinのサーバや中継は使いません。
• 各アカウントに許可する操作を選べます:メールを保全、メールを送信、サーバのメールを変更(確認した変更のみ)。GmailはGoogleのアプリパスワードで接続し、OutlookはMicrosoft自身のページでサインインします。パスワードとトークンはこのデバイスのキーチェーンに保管されます。

その他の機能
• メールを読み、書き、送信できるメールボックス:書式設定、署名、ファイルやアーカイブ済みメッセージの添付、送信の取り消し。
• iPhoneとiPadでも同じアーカイブ機能を利用でき、よくある作業を手順ごとに案内するレシピも用意しています。
• Professionalプラン:カストディアンとリーガルホールド、証拠保全の記録(Chain of Custody)、Bates番号付きのレビューと提出、メールボックスファイル内に残る削除済みメールの復元。
• オプションのデバイス上AIによるインサイト(Apple Intelligence)。オンにするまではオフです。

プライバシーを最優先した設計
• mailinのサーバなし、分析なし、トラッキングなし、当社のアカウント登録も不要。クラウドAIも使いません。

## What's New
ライブメール — 5つの作業がライブメールでも使えるようになりました
• Outlook、Microsoft 365、Gmail、iCloud Mail、Fastmail、または任意のIMAPアカウントを接続できます。オプション機能で、アカウントを追加するまではオフです。デバイスはプロバイダと直接通信し、mailinのサーバや中継は使いません。
• 「メールを保全」は、すべてのメッセージの読み取り専用コピーをアーカイブに保存します。フォルダ、検索、重複処理、検証付き書き出しがそのまま使え、サーバ側で削除されてもアーカイブには残ります。
• Apple Mail風のメールボックスに、Thunderbird風のツールを搭載:メッセージのプレビュー、ポインタを重ねる操作とスワイプ操作、クイックフィルタ(テキスト、未読、フラグ付き、添付ファイル、タグ)、カラータグ、スレッド表示、スマートフォルダ、複数のメッセージへの一括操作。
• 作成と送信:太字、斜体、色、リスト、リンク。アカウントごとの署名。ファイルをドラッグして追加したり、アーカイブから直接メッセージを添付したりできます。送信の取り消しで、送信前にメッセージを保留できます。
• 各アカウントに許可する操作を決められます:メールを保全、メールを送信、サーバのメールを変更(既読やフラグの設定、別のフォルダへの移動、ゴミ箱への移動と復元。指示したときだけ実行され、変更はすべて一覧表示されます)。
• アカウントを削除するときは、メールを残すことも、メールごと削除することもできます。最初に件数を表示し、その後に進行状況を表示します。
• GmailはGoogleのアプリパスワードで、OutlookはMicrosoft自身のサインインで接続します。

高速読み込み
• 大容量のメールボックスの読み込みが数倍速くなりました。メールボックスファイルを並列で読み込み、すべて保存した後に重複を整理します。デフォルトでオンです。読み込みウインドウで、個々の読み込みごとにオフにできます。

その他の新機能
• 高度な検索がすべてのプランで使えるようになりました。検索ボックスの横からワンクリックで開けます(⌥⇧⌘F)。「単語単位」オプションと検索演算子の一覧も用意しています。
• どのページからでも新規メッセージを作成できます(⌥⌘N)。
• 長いメールもすべてのページに全文が印刷されます。すべての日付に年が表示され、日付の範囲と件数は常にリスト全体を表します。
• レシピは、見つけたものと変更したものを表示します。
