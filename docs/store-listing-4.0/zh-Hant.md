## Description

快速開啟大型郵件封存。保留資料夾與附件。找到重要內容。安全處理重複項目。匯出並附上驗證。之後還可透過選用的即時郵件保全，讓封存持續成長——一切都在你自己的 Mac、iPhone 或 iPad 上完成。

1. 快速開啟大型封存
• 支援 MBOX（Google Takeout、Thunderbird、Apple Mail）、EML、EMLX、MSG、PST、OST、Outlook for Mac（OLM）、Lotus Notes（NSF）與 ZIP——直接拖入檔案即可。
• 快速匯入可平行讀取郵件檔案：在我們的測試中，一個 213 MB、包含 56,699 封郵件的信箱在 Apple-silicon Mac 上約 30 秒完成匯入。
• 直接從磁碟串流讀取，大小只受你的儲存空間限制，而非 mailin。無法讀取的內容會如實列出，匯入中斷後會自動繼續。

2. 保留資料夾與附件
• Outlook 資料夾原樣保留，空資料夾也不例外；Gmail 標籤仍是標籤——一封郵件，保留它的所有標籤。
• 每封郵件都保留附件與郵件詳細資訊。封存會為每個郵件檔案保存一份經過驗證的副本，即使原始檔案被移動或刪除，封存依然可用。

3. 找到重要內容
• 可搜尋 PDF、Word、Excel、PowerPoint 與 Pages 檔案內部，以及掃描影像與照片（裝置端 OCR）——並顯示相符位置，開啟附件文字時直接定位到醒目標示的字詞。
• 所有方案皆提供進階搜尋（AND / OR / NOT、日期、寄件人、附件條件）與「全字比對」選項。每次搜尋都會說明涵蓋了封存的多少內容。

4. 安全處理重複項目
• 能區分逐位元組完全相同的副本與僅是相似的郵件，相似郵件絕不會被批次移除。你會先看到數量，移除的副本會移到垃圾桶，可隨時復原。
• 再次加入同一個信箱，不會重複加入任何內容。

5. 匯出並附上驗證
• 支援 PST、MBOX、EML、PDF（每封郵件一個 PDF，以主旨命名）、CSV 等格式。
• 每次匯出都會產生一份收據：讀回匯出結果並與封存比對，任何差異都會明確指出——讓你在從伺服器刪除郵件之前，確認郵件已安全保存。匯出中斷後會自動繼續。

讓封存持續成長
• 隨時加入新的郵件檔案；已在封存中的郵件會自動略過。
• 選用的即時郵件保全：連接 Outlook / Microsoft 365、Gmail、iCloud Mail、Fastmail 或任何 IMAP 帳號，每封新郵件都會保存到你的封存中——即使伺服器刪除了它，也依然保留。在你加入帳號之前此功能保持關閉；你的裝置直接與郵件服務供應商通訊，不經過任何 mailin 伺服器或轉送。
• 由你決定每個帳號可以做什麼：保全郵件、傳送郵件、更改伺服器郵件（僅執行你確認的變更）。Gmail 透過 Google 應用程式密碼連接；Outlook 在 Microsoft 自己的頁面上登入。密碼與權杖保存在本裝置的鑰匙圈中。

同樣包含
• 可閱讀、撰寫與傳送郵件的信箱：格式設定、簽名、附加檔案或已封存的郵件、取消傳送。
• iPhone 與 iPad 上提供同樣的封存功能，還有逐步引導常見工作的配方。
• Professional 方案：保管人與法律保存、監管鏈、審閱與提交（含 Bates 編號）、復原郵件檔案中仍存在的已刪除郵件。
• 選用的裝置端 AI 洞察（Apple Intelligence），在你開啟之前保持關閉。

以隱私為設計核心
• 沒有 mailin 伺服器，沒有分析，沒有追蹤，無需在我們這裡註冊帳號。沒有雲端 AI。

方案：免費、Personal 與 Professional，按月、按年或終身——維持不變。使用條款：https://sasmalgiri.github.io/mailin/terms/

## What's New

即時郵件——五項工作現在也適用於你的即時郵件
• 連接 Outlook 與 Microsoft 365、Gmail、iCloud Mail、Fastmail 或任何 IMAP 帳號——選用功能，在你加入帳號之前保持關閉。你的裝置直接與郵件服務供應商通訊：沒有 mailin 伺服器，沒有轉送。
• 「保全郵件」會將每封郵件的唯讀副本保存到你的封存中，讓資料夾、搜尋、重複項目與驗證匯出都能套用在這些郵件上——即使伺服器刪除了郵件，它也依然保留。
• Apple Mail 風格的信箱，搭配 Thunderbird 風格的工具：郵件預覽、游標停留與滑動操作、快速篩選（文字、未讀、已加旗標、附件、標籤）、彩色標籤、對話、智慧型資料夾，以及同時對多封郵件執行操作。
• 撰寫與傳送：粗體、斜體、顏色、列表與連結；每個帳號各自的簽名；拖入檔案，或直接從封存中附加郵件。「取消傳送」會在郵件寄出前暫時保留。
• 由你決定每個帳號可以做什麼：保全郵件、傳送郵件與更改伺服器郵件（標示、加旗標、移到其他資料夾、移到垃圾桶並復原——僅在你要求時執行，每項變更都會列出）。
• 移除帳號時可保留其郵件，也可一併刪除——先顯示數量，再顯示進度。
• Gmail 透過 Google 應用程式密碼連接；Outlook 使用 Microsoft 自己的登入頁面。

快速匯入
• 大型信箱的匯入速度提升數倍：平行讀取郵件檔案，所有內容保存完畢後再整理重複項目。預設開啟；可在匯入視窗中為任何一次匯入單獨關閉。

其他新功能
• 進階搜尋現已在所有方案中提供——而且就在搜尋框旁邊，一鍵即達（⌥⇧⌘F），附帶「全字比對」選項與搜尋運算子列表。
• 在任何頁面新增郵件（⌥⌘N）。
• 長郵件在每一頁上都完整列印；每個日期都顯示年份；日期範圍與數量始終描述整個列表。
• 配方會顯示它找到了什麼、變更了什麼。
