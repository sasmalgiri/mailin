COMING IN VERSION 2.0

A foundation rewrite, under the same UI.

mailin 2.0 keeps every v1 feature — the persona-driven UI, the full analysis suite, the on-device AI — and rebuilds the storage, ingest, and search layers underneath for archives that were never realistic on v1.

💧

Streaming ingest

Drop a 200 GB Gmail Takeout and walk away. v2 drains messages in batches of 200; peak memory stays flat regardless of file size.

♻️

Resumable from any crash

Per-file SHA-256 plus per-batch checkpoints. A crash 800 GB into an import resumes from the last batch — re-work capped at one batch of 200 messages.

🔎

Year-sharded FTS5

Search splits across per-year SQLite shards with bm25 ranking. Time-bounded queries hit one shard; cross-archive queries fan out and merge.

⚡

Keyset pagination

Jump to email #1,000,000 — it responds in a heartbeat. The old offset-scan freeze at depth is gone. Stable across timestamp ties.

🗺️

Larger PST / NSF

Memory-mapped readers. PST/OST up to 50 GB; NSF up to 64 GB. Multi-GB files no longer materialise in RAM.

🔒

Same privacy posture

No telemetry, no analytics, no third-party SDKs. v2 stores data in the exact same on-device location as v1 — existing users get a free in-place upgrade.

Still offline by default. mailin v2 contains no IMAP, no SMTP, no live-mail code in its shipped binary. Your archive stays on your device. That's not a temporary posture — it's the product.

Under the hood

For the technically curious — exactly how mailin works.

🧩

Parsers, hand-written in Swift

MBOX, EML, EMLX, MSG, PST, OST, NSF — all parsed natively. RFC 822 + full MIME compliance: multipart, base64, quoted-printable, charset decoding. Streaming parser so 10GB+ Gmail Takeouts don't OOM.

🔎

Search: BM25 + boolean + regex + proximity

Full-text index built locally. Operators: AND/OR/NOT, regex, NEAR/n. Indexes subject, headers, body. Threading via Message-ID / In-Reply-To / References.

🧠

On-device AI stack

Apple NaturalLanguage for sentiment, entities, language detection. Foundation Models (macOS 26+) for summaries and Q&A. All local — no cloud model, no API key, no network round-trip.

🔒

Privacy enforcement, not just claims

mailin ships with no network entitlement — the sandboxed binary cannot make a network call, period. No telemetry, no analytics, no data collection. Every AI output is tagged with the on-device engine that produced it (AIProvenance).

🛡️

Data integrity

SHA-256 hash on every email at import. HMAC-chained audit log where each entry signs the previous (tamper-evident). Ed25519-signed exports. Bates numbering with configurable prefix and padding.

👁️

Source available

Code lives at github.com/sasmalgiri/mailin so the privacy claims can be audited. Proprietary license — not open source, but readable.
