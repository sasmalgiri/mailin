# Apache Tika OpenDocument and iWork test documents (downloaded 2026-11-07)

Real files written by OpenOffice.org 2/3, NeoOffice 2.2, LibreOffice, and by Pages, Numbers and Keynote
('09 XML, 2013 IWA, 2018 zipped bundle), taken from the test corpus of Apache Tika
(https://github.com/apache/tika, branch `main` on 2026-11-07). Licence: Apache License 2.0
(https://www.apache.org/licenses/LICENSE-2.0). The files are test data and are used here only to verify
mailin's readers (`TikaODFIWorkFixtureTests`, one test per file); the phrases asserted are the ones Tika's
own `ODFParserTest.java` and `IWorkParserTest.java` assert.

Known passwords: `testODTEncrypted.odt` (LibreOffice, AES-256-CBC / PBKDF2 100,000 / SHA-256) opens with
`tika`; `testPagesPwdProtected.pages` (iWork '09, Apple ZIP methods 25451/25452) has the password `tika`
too: locked without a password, opened with it since audit R6 (`IWork09Encryption`; Tika does not open
it, TIKA-903).
