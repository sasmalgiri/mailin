**Build walked:** branch `v3-architecture`, starting at `f5957e9`. The build is **Debug**, scheme **"maxmailin Connected"**, installed with Xcode Install & Run and launched with `-mailinSimulateTier professional` so the duplicate tools (Personal and above) are available. ## Open (recorded, not changed)
- **Hyphenated hashes and addresses (iOS 27 typesetting):**
  - The import receipt's SHA-256 and content hash break across lines with an inserted hyphen ("…c019e-/b5312…") on iPhone (`iphone-04`).
  - In the iPad header card, addresses break as "carol@example.-com" (`ipad-20`).
  - SwiftUI has no hyphenation switch for `Text`, so a fix means a different way of drawing these values (for example selectable monospaced text with a character-wrapping `UILabel`). It is cosmetic, but a copied-by-eye hash would be wrong. **Owner decision.**
- **v1 "Folders" block:** "Inbox 7" (meaning received mail) sits above Source Folders, where Inbox is 3. This is confusing; it is old code (rule 14), and F-3 on 2026-11-08 already noted it.
- **Old-engine Subjects panel:** it keeps "7 subjects" after a move to the Trash (previous-engine window).
- **Export Emails placement:** on iPad, Export Emails / Apply / Clear sit at the bottom of the sidebar's scroll content, so they are hidden until the sidebar is scrolled.
- **Main-screen subtitle:** "Open an mbox or eml file…" undersells the nine formats listed below it.
- **Ordering-dependent unit test:** `V2SearchTests.testIPAD04_zipAttachmentContentsAreListedForTheMessage` failed once when run right after `IPadGate1FixTests` (0 child rows). It passed alone and in the full `V2SearchTests` + `IPadGate1FixTests` run. This is pre-existing; the indexing job's timing is shared between the classes.
