mailin Privacy Policy

Effective Date: September 29, 2026 (version 3.0). The hosted copy of this policy at the app's privacy URL is the one of record; this file mirrors it.

mailin does not collect, store, transmit, or share any personal data with the developer. There is no developer server.

Data Collection

mailin collects zero user data. We do not collect analytics, usage data, crash reports, device information, or any other personal information.

Email Processing

All email parsing, search, filtering, analysis and default AI features happen entirely on your device, using Apple's on-device NaturalLanguage framework and, on macOS 26 and later, Apple Intelligence's on-device models through the FoundationModels framework.

Optional Cloud AI

mailin offers an optional Cloud AI mode that uses a third-party provider (OpenAI or Anthropic). It is off by default, requires your own API key, and asks you to confirm each request before anything is sent. Only the excerpts relevant to your request go to the provider you chose, directly, never through us. Those providers' own privacy policies apply to what they receive.

Live Mail (not included in version 3.0)

Version 3.0 does not connect to any mail account. The Live Mail page is a placeholder and states this in the app: no account can be added and no mail server is contacted. If Live Mail ships in a later version, this policy will be updated first.

Network Access

mailin does not require an internet connection for anything it does with your archive. Network activity is limited to Apple's StoreKit for in-app purchases and, only if you enable it, the optional Cloud AI requests described above.

Data Storage

Your archive is a folder you own, stored locally in mailin's app container or, if you move it, on a disk you choose. Moving makes a verified copy and never deletes the old one until the new one is in use. Single messages larger than 100 MB are not copied into the archive: mailin records where the message sits in the file you imported and reads it from there, after checking the file is still the one that was imported. You can clear all saved data at any time from Settings.

Third-Party Services

mailin does not integrate any third-party analytics, advertising, or tracking services. The only third-party services are the optional Cloud AI providers above, used with your own key.

In-App Purchases

Purchases are processed by Apple through the App Store. Apple's privacy policy governs how purchase transactions are handled. mailin does not have access to your payment information.

Children's Privacy

mailin does not knowingly collect any information from anyone, including children under the age of 13.

Changes to This Policy

If we change this policy, we will update this page and the date above before the change takes effect.
